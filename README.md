# Cost Service

Веб-сервис для расчёта стоимости приложений и их компонентов в месяц.

- **Сервер** (или ВМ, СХД) описывается в разделе «Серверы» и состоит из комплектующих: процессор, память,
  диски (HDD/SSD/NVMe), сеть, лицензии и прочее. У каждого комплектующего есть ТТХ (модель, ёмкость,
  характеристики) и цена. Цену можно указать в месяц (аренда, облако) или как цену покупки со сроком амортизации.
  Отдельно задаются **расходы на обслуживание**: электроэнергия, колокация, техподдержка, администрирование —
  суммой в месяц, в год или процентом в год от цены покупки комплектующих (типично для вендорской поддержки).
- **Сервис** — приложение, например Elasticsearch. Ему выделяются серверы: весь сервер или конкретные ресурсы —
  ядра CPU, ГБ памяти, ГБ дисков каждого типа, GPU, сеть. Так один сервер можно разделить между сервисами:
  например, Elasticsearch — 32 ядра, 128 ГБ памяти и 5 ТБ SSD, PostgreSQL — 12 ядер, 96 ГБ и 2 ТБ.
- **Дисковое подпространство** объединяет диски одного типа на серверах сервиса и задаёт цену 1 ГБ в месяц:
  стоимость дисков делится на полезный объём. Цену можно задать и вручную.
- **Ресурс** — например, datastream Elasticsearch. Размер берётся из Prometheus по PromQL-запросу (или задаётся
  вручную). Стоимость хранения = размер × цена ГБ подпространства.

Для каждого сервиса видно, сколько стоит инфраструктура и хранение, какая часть хранения распределена по ресурсам
и сколько стоит свободное место (оплачено, но не занято).

## Быстрый старт

### Docker Compose

```bash
cp .env.example .env          # PROMETHEUS_URL, TIMEZONE, ADMIN_USERNAME/ADMIN_PASSWORD ...
docker compose up -d --build
```

Интерфейс: http://localhost:8001

Контейнер работает в сети хоста (`network_mode: host`): `http://localhost:9090` — это Prometheus на этом хосте.
Порт 8001 выбран потому, что 8000 занимает соседний es-query-service.

### Без Docker

```bash
python3 -m virtualenv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/uvicorn app.main:app --port 8001
```

При первом запуске сервис предложит создать администратора (или возьмёт его из `ADMIN_USERNAME`/`ADMIN_PASSWORD`).

## Как пользоваться

1. **Управление → Prometheus**: добавьте источник. Подойдёт любой сервер с API Prometheus: Prometheus,
   VictoriaMetrics, Thanos, Mimir. Поддерживаются авторизация по логину и паролю или по токену (Bearer)
   и отключение проверки TLS.
2. **Серверы → + Новый сервер**: название, хост, комплектующие. В таблице комплектующих указываются
   категория, модель, ТТХ, ёмкость одной штуки, количество и цена одной штуки. Стоимость в месяц считается
   прямо в форме. Одинаковые серверы удобно создавать сразу пачкой: «Сколько создать» = 6 даст es-hot-01 … es-hot-06.
   Кнопка «Копия» на странице сервера создаёт похожий сервер.
3. **Новый сервис**, например `Elasticsearch`, затем **+ Добавить серверы**: отметьте серверы и укажите,
   что выделить сервису — «Весь сервер» или количество каждого ресурса (по умолчанию подставлено всё свободное).
   Стоимость выделенного считается прямо в форме. Больше свободного выделить нельзя: что уже занято другими
   сервисами, видно в разделе «Серверы». Выделение можно изменить («Изменить») или убрать сервер из сервиса.
4. **+ Подпространство**: тип дисков (например, NVMe) и полезный объём в процентах от сырого:
   RAID 10 — 50%, к этому запас на файловую систему и watermark ES. Если не отметить серверы,
   в подпространство войдут диски этого типа со всех серверов сервиса.
5. **+ Ресурс**: подпространство и PromQL-запрос, который возвращает размер в **байтах**. Кнопка
   «Проверить запрос» сразу показывает текущее значение.

### Расчёт

| Величина | Формула |
|---|---|
| Комплектующее в месяц | цена × шт. (покупка: цена ÷ срок амортизации × шт.) |
| Обслуживание в месяц | сумма в месяц; в год ÷ 12; % в год × цена покупки комплектующих ÷ 12 |
| Сервер в месяц | комплектующие + обслуживание |
| Цена единицы ресурса | стоимость комплектующих вида ÷ их ёмкость (например, цена ядра = процессоры ÷ ядра) |
| Сервер в сервисе | Σ (выделено × цена единицы) + прочие расходы сервера × (выделено ÷ стоимость всех ресурсов) |
| Весь сервер | стоимость сервера целиком |
| Полезный объём подпространства | Σ ГБ дисков этого типа, выделенных сервису × полезный % |
| Цена ГБ в месяц | стоимость выделенных дисков ÷ полезный объём (или вручную) |
| Стоимость ресурса | размер × множитель × цена ГБ |
| Свободное место | стоимость подпространства − стоимость его ресурсов |

Объёмы считаются в десятичных единицах, как в маркировке дисков: 1 ГБ = 10⁹ байт, 1 ТБ = 1000 ГБ.
В цену ГБ входят только диски. Процессоры, память и прочее учитываются в стоимости инфраструктуры сервиса.
Комплектующие без ёмкости (лицензии, стойко-место, прочее) и расходы на обслуживание не выделяются отдельно:
сервис несёт их часть пропорционально стоимости выделенных ему ресурсов.

### PromQL для Elasticsearch

Нужен [elasticsearch_exporter](https://github.com/prometheus-community/elasticsearch_exporter) с флагом `--es.indices`:

```promql
# datastream целиком, с репликами
sum(elasticsearch_indices_store_size_bytes_total{index=~".ds-logs-app-prod-.*"})

# только primary-шарды: в ресурсе укажите множитель = 1 + число реплик
sum(elasticsearch_indices_store_size_bytes_primary{index=~".ds-logs-app-prod-.*"})
```

Запрос должен вернуть число или вектор (несколько рядов суммируются). Пустой результат, `NaN` и matrix считаются
ошибкой: ресурс сохраняет последний удачный размер, а ошибка видна в таблице ресурсов.

Размеры обновляются каждые `METRICS_REFRESH_MINUTES` минут, а также кнопками «Обновить размеры» (весь сервис)
и «Обновить размер» (ресурс). История хранится `METRICS_HISTORY_DAYS` дней, на странице ресурса показаны график
и прирост за период.

## Валюты

Все суммы хранятся в долларах. Курсы EUR и RUB к доллару задаёт администратор в «Управление → Валюты»
(«1 $ = … €», «1 $ = … ₽»). Каждый пользователь переключает валюту показа в шапке ($ € ₽): в выбранной валюте
показываются все суммы и вводятся цены в формах (они пересчитываются в доллары при сохранении). Пока курс
не задан, валюта недоступна. Изменение курса меняет суммы в этой валюте, сохранённые долларовые цены не меняются.

## Пользователи и роли

| Роль | Права |
|---|---|
| наблюдатель | просмотр серверов, сервисов и стоимости |
| редактор | плюс создание и изменение серверов, сервисов, подпространств и ресурсов |
| администратор | плюс пользователи, источники Prometheus и курсы валют |

Адреса Prometheus задаёт только администратор: редактор выбирает источник из списка и не может направить запросы
сервиса на произвольный адрес.

## JSON API

Работает с сессией вошедшего пользователя.

Суммы — в долларах (поле `currency`); `?currency=EUR` или `?currency=RUB` пересчитывает их по курсу.

- `GET /api/services` — все сервисы с расчётом;
- `GET /api/services/{id}` — один сервис: выделенные ресурсы серверов, стоимость подпространств и ресурсов в месяц;
- `POST /api/promql/test` `{"source_id": 1, "promql": "..."}` — проверить запрос (редактор).
